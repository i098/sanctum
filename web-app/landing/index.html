Sanctum is an open-source meeting listener that sits quietly in a browser tab. It keeps the full transcript and a private recording, and turns what you decide into memory your agents can read.

How it works

From the room to your agents.

  1. listen

    Open Sanctum in a browser tab on a room computer or laptop and allow the microphone. There is nothing to install. It listens only while the tab is open and the device is awake, and it never speaks up on its own.

  2. separate

    Sanctum finds where one meeting ends and the next begins. End a meeting yourself, or split and merge meetings later through the API.

  3. keep

    Every meeting keeps its full transcript and a private recording, whatever its notes and memory leave out.

  4. remember

    Notes, decisions and commitments become memory that knows when it was true. Each item is versioned, linked to the transcript passage it came from, and visible only to people who may see that meeting.

  5. share

    Agents read and add context through remote MCP and the TypeScript and Python SDKs, with the same permission checks as the website.

For agents

Connect any MCP client.

Sign in once through OAuth. An agent never gets more access than the person who connects it, and each item carries its revision and sources, so an agent can check what it reads and add to it without overwriting.

Run it

Use the hosted preview, or run your own.

Hosted preview

  • Sign in and create a workspace for your team.
  • Speech-to-text, notes and memory run on Cloudflare Workers AI.
  • Recordings stay in a private bucket.
Open Sanctum

Self-host

  • Docker Compose: MySQL 8.4, the API and job worker from one Node image, and Caddy for HTTPS.
  • Your own Cloudflare R2 bucket for recordings, and your own Workers AI token for speech-to-text, notes and memory.
  • Built-in sign-in, or your own OIDC issuer.
  • Bring your own keys for speaker labels, spoken replies and integration actions.
