Context search answers questions. A query that contains a question or helper word (such as `who`, `the`, `does`, `we`, `and`, `not` or a possessive `'s`) is a question: up to 40 current items the caller may read that share a content word with it go to the configured `classifier` model, with the planner model as fallback, which picks the items that answer it; they list newest first, and `next_cursor` continues the same picks. A model failure returns 503 `unavailable` instead of a word-match guess. Keyword queries without those words still need every word and do not call a model; a keyword query that contains one of them is now read as a question, unless the request sets `mode=keyword`. The Menu search box sets `mode=keyword`, so typing in it never calls a model
